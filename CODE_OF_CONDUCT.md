# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, keep criticism about the work and not the person,
and do not harass anyone. Unacceptable behaviour can be reported to the maintainer through a GitHub issue or,
if that is not appropriate, through a private message on GitHub. Reports are handled in confidence.
