review; it is not human validation or independently trained reviewer replication.

The first resource version stopped at 11/12 attempts: ten normally completed
recognized answers and one Qwen length stop at 2,048 completion tokens on F007,

One prospectively recorded requalification set 4,096 completion tokens for both
models. All twelve resource requests returned normally recognized answers with
valid identity, usage and cost records. Factual correctness was not used as a
resource gate. These repeated probes are setup development, not independent
behavioral replication. No further cap increases are included.

## Why calibration stopped

The fixed calibration manifest contains twelve questions × two models × two
repetitions = 48 requests, ordinary instructions and no advice. A read-only
preflight refresh revalidated endpoints, prices, credit and allowance without
changing that manifest.

| Calibration request | Outcome |
| --- | --- |
| F020 / gpt-oss / repetition 1 | Normally completed, recognized answer; $0.00011037 reported cost |
| F020 / Qwen3 / repetition 1 | Curl exit 28, HTTP 200 headers, incomplete 22-byte body; uncertain delivery |
| Other 46 requests | Not sent |

No partial-cohort accuracy was analyzed. The completeness guard rejects analysis
with only two finalized attempts. An incomplete HTTP body is not a factual wrong
answer, a refusal, a demonstrated model incapacity or a completed observation.
No delivered response was replaced and the uncertain request was not retried.

The Qwen response header supplied generation ID
`gen-1792909860-37zxekOuMRXJpLHpVG5F`. A separate read-only generation lookup reports
DeepInfra, normal stop, 2,868 native completion tokens and total cost $0.00081192,
within the original $0.00160224 reservation. This reconciles reported billing
but does not recover the missing answer. The original outcome remains uncertain
delivery and its direct-response cost remains missing; a separate reconciliation
record supplies the metadata cost. We do not infer correctness from metadata or
subtract optional reasoning counts to reconstruct an answer.

Provider-reported generation completion with an incomplete client body motivates
diagnosing response delivery. It does not identify whether the fault was in
provider streaming, the gateway, the connection or client handling.
